permanent fix:

STEP 1 — Check if you have a PowerShell profile
Open Windows Terminal → PowerShell, then run: Test-Path $PROFILE
If it prints: false
Create it: New-Item -Path $PROFILE -Type File -Force

STEP 2 — Open the PowerShell profile
Run: notepad $PROFILE
This will open a file like: C:\Users\<you>\Documents\PowerShell\Microsoft.PowerShell_profile.ps1

STEP 3 — Add this line to the profile
Paste this into the file: [Console]::OutputEncoding = [System.Text.UTF8Encoding]::new()

OPTIONAL — Also force UTF-8 input (recommended)
$OutputEncoding = [System.Text.UTF8Encoding]::new()
Save → Close Notepad.

Allow only the current user to run scripts
